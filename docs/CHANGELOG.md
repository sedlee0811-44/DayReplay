# 更新日志

格式：`## [版本] - 日期` + 要点列表。build_package.py 打包时会读取
**最顶部**这一段的要点，写进 VERSION.json，用户更新时看到的就是它。

## [1.1.1] - 2026-10-25

- 修复：更新器适配平铺安装布局（此前更新只换了备份副本，运行的代码不更新）
- 修复：`__pycache__` 不再参与签名（此前装好后一运行就会误报"有更新"）
- 修复：文件清单排序口径统一（大小写文件名的排序差异曾导致签名对不上）
- 新增：版本号相同但文件不符时自动自我修复；更新完成后逐文件复检，不符自动回滚

## [1.1.0] - 2026-10-25

- 总账顶部版本条显示构建日期（一眼看出这套系统是什么时候装的）
- 安装器收尾现在能正确显示版本号（PS 5.1 读中文 JSON 会静默失败，已改用 python 读）

- 首发：语音录音 / 语音转写 / 声纹识别 / 人类活动声识别 / 总账时间轴 / 自然语言搜索
